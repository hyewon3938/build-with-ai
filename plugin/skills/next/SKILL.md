# /next - 다음 세션 시작 스킬

대기열 파일 `LOCAL-SESSIONS.md`에서 다음에 열 세션을 고르고, 열 수 있는지 확인한 뒤 `/build` 절차로 구현을 시작한다. 특정 세션을 열 때는 `/build <세션 이름>`을 쓴다.

## 실행 흐름

### 1. 대기열 읽기

대기열 파일은 「지금」 절에 보고가 쌓여 수십 KB를 넘기 쉽고, 통째로 읽으면 그 내용이 세션이 끝날 때까지 호출마다 다시 읽힌다. 그래서 파일을 Read로 통째로 읽지 않고, `<이 스킬 폴더>/../../scripts/queue-read.mjs`를 realpath로 푼 경로로 필요한 부분만 읽는다. 스크립트는 `git worktree list --porcelain`의 첫 worktree인 메인 체크아웃에서 `LOCAL-SESSIONS.md`를 찾으므로 worktree 안에서 불러도 같은 파일을 읽는다. 파일이 없으면 종료 코드 1로 끝나니 대기열이 없다고 알리고 끝낸다.

- `--outline`: 절마다 줄 범위와 크기, 「지금」과 남은 작업의 불릿마다 첫머리 100자와 줄 범위. 첫 줄에 파일 경로가 나온다.
- `--section 일정`: 일정 표
- `--rows`: 대기열 행마다 순서, 세션, 이슈, 모델, 선행, 날짜, 상태를 줄여 한 줄씩
- `--next`, `--row <세션>`: 2단계와 3단계에서 쓴다.
- `--lines a-b`: 불릿 하나처럼 정한 줄 범위

먼저 `--outline`과 `--section 일정`을 본다. 불릿 본문은 첫머리로 판단이 안 될 때만 `--lines`로 그 불릿만 읽는다. 고칠 줄은 Read 도구에 offset과 limit을 줘서 그 범위만 읽은 뒤 Edit로 고친다.

일정 표에 오늘보다 앞선 날짜 줄이 있으면 `<이 스킬 폴더>/../design/references/queue.md` 「지난 일정 정리」대로 정리하고, 옮긴 할 일과 물어볼 것을 알린다. 「지금」과 남은 작업의 불릿 첫머리를 `--rows`와 대조해서, 대기열이나 배포 대기 표에 이미 행이 있는 항목과 닫힌 이슈로 끝난 항목은 같은 문서 「지금과 남은 작업 정리」대로 지우고 지운 항목을 알린다.

### 2. 세션 고르기

고르기 전에 「지금」 절의 사용자가 정해야 하는 일과, 남은 작업 가운데 다시 볼 날짜가 오늘이거나 지난 항목을 확인한다. 사용자가 정해야 하는 일은 `--outline`이 보여 준 그 불릿의 줄 범위를 `--lines`로 읽고, 남은 작업은 불릿 첫머리의 다시 볼 날짜를 보고 날짜가 된 불릿만 읽는다. 있으면 항목마다 정할 것을 한 줄씩 알리고 `/design <주제>`로 설계하자고 제안한 뒤 이어간다. 다시 볼 날짜가 된 항목은 `<이 스킬 폴더>/../design/references/queue.md` 「남은 작업에 넣는 기준」으로 다시 나눠서 알린다.

`--next`로 대기열 표에서 상태가 대기인 행 가운데 순서가 가장 앞선 행을 고른다. 출력에는 그 행의 칸 전체와 뒤 순서 대기 행의 선행, 날짜, 손댈 파일, 진행 중이거나 머지 전 확인 상태인 행이 함께 나온다. 진행 중이거나 머지 전 확인 상태인 행이 있으면 함께 알린다. 머지 전 확인 행은 사용자가 확인을 마쳤다고 하면 `/build <그 세션>`으로 이어간다.

### 3. 시작 전 확인

`<이 스킬 폴더>/../build/SKILL.md`를 읽고, 그 2단계의 시작 전 확인 가운데 1~3을 고른 행에 대해 한다. 열린 PR 목록과 worktree 목록은 한 번만 가져와 모든 행에 쓴다.

하나라도 걸리면 그 자리에서 멈추고, 아래 내용을 알린 뒤 AskUserQuestion으로 어떻게 할지 묻는다. 뒤 순서의 세션을 대신 열지는 사용자가 정한다. 대기열 「지금」 절에 자율 진행 불릿이 있으면 묻지 않고 build SKILL.md 「자율 진행」 절대로 한다.

- 세션 이름과 걸린 확인
- 행의 여는 날짜와 이유
- 남은 선행 세션, 겹치는 PR이나 worktree와 파일
- 지금 열 수 있는 뒤 순서 세션: `--next`의 뒤 순서 대기 행에 같은 확인을 해서 통과한 행. 잘린 칸을 다 봐야 하면 `--row <세션>`으로 그 행만 읽는다.

선택지는 기다리기, 통과한 뒤 순서 세션 열기, 걸린 세션을 그대로 열기 3가지다. 통과한 세션이 없으면 두 번째 선택지는 뺀다.

### 4. 모델 확인

열 세션이 정해지면 그 행에 build SKILL.md 2단계의 4번 모델 확인을 하고, 걸리면 그 절차대로 멈추고 묻는다. 자율 진행 중 줄의 뒤 세션이면 「자율 진행」 절의 모델 규칙을 따른다.

### 5. 시작

모델 확인을 통과했거나 사용자가 지금 모델로 계속하기로 하면, build SKILL.md의 1단계 맥락을 읽고 3단계부터 따른다. 대기열 상태는 3단계에서 진행 중으로 바뀐다. build의 references는 `<이 스킬 폴더>/../build/references/`에서 읽는다.
