# /next - 다음 세션 시작 스킬

대기열 파일 `LOCAL-SESSIONS.md`에서 다음에 열 세션을 고르고, 열 수 있는지 확인한 뒤 `/build` 절차로 구현을 시작한다. 특정 세션을 열 때는 `/build <세션 이름>`을 쓴다.

## 실행 흐름

### 1. 대기열 읽기

메인 체크아웃 경로를 `git worktree list --porcelain`의 첫 `worktree` 줄에서 얻고, 그 경로의 `LOCAL-SESSIONS.md`를 읽는다. worktree 안에서 불렀어도 같은 경로를 쓴다. 파일이 없으면 대기열이 없다고 알리고 끝낸다.

일정 표에 오늘보다 앞선 날짜 줄이 있으면 `<이 스킬 폴더>/../design/references/queue.md` 「지난 일정 정리」대로 정리하고, 옮긴 할 일과 물어볼 것을 알린다.

### 2. 세션 고르기

고르기 전에 「지금」 절의 사용자가 정해야 하는 일과, 남은 작업 가운데 다시 볼 날짜가 오늘이거나 지난 항목을 확인한다. 있으면 항목마다 정할 것을 한 줄씩 알리고 `/design <주제>`로 설계하자고 제안한 뒤 이어간다. 다시 볼 날짜가 된 항목은 `<이 스킬 폴더>/../design/references/queue.md` 「남은 작업에 넣는 기준」으로 다시 나눠서 알린다.

대기열 표에서 상태가 대기인 행 가운데 순서가 가장 앞선 행을 고른다. 진행 중이거나 머지 전 확인 상태인 행이 있으면 함께 알린다. 머지 전 확인 행은 사용자가 확인을 마쳤다고 하면 `/build <그 세션>`으로 이어간다.

### 3. 시작 전 확인

`<이 스킬 폴더>/../build/SKILL.md`를 읽고, 그 2단계의 시작 전 확인 가운데 1~3을 고른 행에 대해 한다. 열린 PR 목록과 worktree 목록은 한 번만 가져와 모든 행에 쓴다.

하나라도 걸리면 그 자리에서 멈추고, 아래 내용을 알린 뒤 AskUserQuestion으로 어떻게 할지 묻는다. 뒤 순서의 세션을 대신 열지는 사용자가 정한다.

- 세션 이름과 걸린 확인
- 행의 여는 날짜와 이유
- 남은 선행 세션, 겹치는 PR이나 worktree와 파일
- 지금 열 수 있는 뒤 순서 세션: 뒤 행에 같은 확인을 해서 통과한 행

선택지는 기다리기, 통과한 뒤 순서 세션 열기, 걸린 세션을 그대로 열기 3가지다. 통과한 세션이 없으면 두 번째 선택지는 뺀다.

### 4. 모델 확인

열 세션이 정해지면 그 행에 build SKILL.md 2단계의 4번 모델 확인을 하고, 걸리면 그 절차대로 멈추고 묻는다.

### 5. 시작

모델 확인을 통과했거나 사용자가 지금 모델로 계속하기로 하면, build SKILL.md의 1단계 맥락을 읽고 3단계부터 따른다. 대기열 상태는 3단계에서 진행 중으로 바뀐다. build의 references는 `<이 스킬 폴더>/../build/references/`에서 읽는다.
