# 배포 기록과 목록 갱신

## LOCAL-HISTORY.md 배포 기록

파일 끝에 붙인다. 앞 기록과 굵은 라벨이 다르면 앞 기록을 따른다. 배포 시각은 빌드와 재시작을 마친 시각이다.

```markdown
## <YYYY-MM-DD HH:MM> 배포 — <바꾼 내용>(#<이슈> PR #<PR>), <바꾼 내용>(#<이슈> PR #<PR>)

앞 배포 `<커밋>`(<M/D HH:MM>) → 이번 `<커밋>`. 무엇을 함께 올렸는지와 이 단위로 올린 이유.

**로컬 검사.** 돌린 검사와 통과 건수, CI 결과.

**백업.** 백업 파일 경로, 무결성 검사 결과, 크기. 저장한 로그 파일 경로.

**지울 옛 사본.** `--diff-filter=DR` 결과와 원격에서 지운 파일. 없으면 없음.

**올린 것.** dry run 파일 수와 `git diff --name-only` 대조 결과, 제외 목록 차이, 올린 뒤 dry run에 남은 차이.

**확인.** 컨테이너 상태, 기동 로그, 해시 대조, 배포 절의 추가 확인 결과.

**함께 한 일.** 적용한 패치나 조회와 그 결과. 없으면 이 라벨을 뺀다.

**볼 것.** 배포 시각을 넣은 `LOCAL-TRACK.md` 묶음 제목.
```

## LOCAL-TRACK.md 묶음 머리 줄

묶음 형식은 `<이 스킬 폴더>/../build/references/wrap-up.md`의 「배포 뒤 확인 묶음」 절에 있다. 배포 시각은 머지 날짜 뒤에 넣는다.

```markdown
<M/D> 머지 · <M/D HH:MM> 배포 · 이슈 #N · PR #M
```

- 옛 형식 머리 줄에 배포 예정이라는 말이 있으면 그 부분을 `<M/D HH:MM> 배포`로 바꾼다.
- 한 묶음의 PR 가운데 일부만 이번에 올렸으면 `<M/D HH:MM> 배포(PR #M)`처럼 올린 PR 번호를 함께 적는다.
- 올린 PR에 묶음이 없고 운영에서 볼 것이 있으면 위 형식으로 묶음을 만들고, 머리 줄에 배포 시각을 함께 넣는다.

## LOCAL-SESSIONS.md

- 배포 대기 표에서 이번에 올린 세션의 행을 지운다. 표 위 문단에 배포 경위를 덧붙이지 않는다.
- 마지막 배포를 적은 줄을 이번 배포 시각, 올린 커밋, `LOCAL-HISTORY.md` 기록 위치로 고친다.
- 일정 표에서 이번 배포 할 일을 지우고, 그 줄에 다른 할 일이 남지 않으면 줄도 지운다. 배포했다는 결과는 일정 표에 적지 않고 마지막 배포 줄과 `LOCAL-HISTORY.md`에만 적는다. 배포 뒤 확인 항목 가운데 날짜를 정해 볼 것이 있으면 그 날짜로 `/track` 확인 줄을 넣는다. 오늘보다 앞선 날짜 줄이 있으면 `<이 스킬 폴더>/../design/references/queue.md` 「지난 일정 정리」대로 함께 정리한다.
- 대기 순서처럼 세션 이름을 나열한 줄에 올린 세션이 남아 있으면 함께 지운다.
