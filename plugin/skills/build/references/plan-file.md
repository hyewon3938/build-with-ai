# 계획서로 진행하는 세션

대기열 행 대신 `/design`이 만든 `.claude/plans/<이슈>-*.md` 계획서로 진행할 때 쓴다.

## 읽기

- 인자로 경로를 받았으면 그 파일을, 아니면 `ls -t .claude/plans/*.md`의 첫 파일을 읽는다. 계획서도 대기열도 없으면 `/design`을 먼저 돌리라고 알리고 끝낸다.
- 계획서의 이슈, 브랜치, 구현 상세, 커밋 계획, 테스트 계획이 대기열 행의 할 일과 손댈 파일을 대신한다. 시작 전 확인의 파일 겹침은 구현 상세에 나온 파일로 본다.
- 완료 게이트 절이 있으면 완료 보고 전 자기 점검 기준으로 쓰고, 게이트를 채우지 못했으면 완료 대신 지금 상황을 보고한다. 절이 없으면 구현 상세와 테스트 계획으로 게이트를 만든다.

## 구현

- 계획서에 없는 변경이 필요하면 먼저 묻는다.
- 계획서의 Before/After 코드와 지금 코드가 다르면 지금 코드를 기준으로 판단하고 그 사실을 알린다.
- 커밋은 계획서의 커밋 계획을 따른다.

## 아카이브

계획서를 `.claude/plans/_archive/`로 옮기고, `.claude/plans/` 바로 아래에 이슈가 이미 닫힌 계획서가 있으면 함께 옮긴다. 계획서가 gitignored면 머지 뒤 메인 체크아웃 경로에서 옮기고, git이 추적하는 파일이면 머지 전에 PR 브랜치에서 옮긴다.
