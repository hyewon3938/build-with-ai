# 머지 뒤 마무리

## worktree와 브랜치 정리

`/build`는 사용자만 부르는 스킬이고 정리까지가 요청 범위라서, 이 단계에서 worktree를 나와 지운다.

1. 메인 체크아웃의 base 브랜치를 최신으로 맞춘다. 메인 체크아웃이 base 브랜치에 있으면 `git -C <메인> pull --ff-only`를, 다른 브랜치에 있으면 `git -C <메인> fetch origin <base>:<base>`를 쓴다.
2. EnterWorktree로 들어온 세션이면 ExitWorktree에 `keep`을 주고 원래 디렉터리로 돌아온다. `path`로 들어온 worktree는 ExitWorktree가 지우지 못하므로, 지우는 일은 어느 경우든 다음 단계의 git 명령으로 한다.
3. worktree와 로컬 브랜치를 지운다.

   ```bash
   git -C <메인> worktree remove <worktree 경로>
   git -C <메인> branch -d <브랜치>
   ```

   - 링크한 문서는 링크만 지워지고 메인 체크아웃의 원본은 남는다.
   - `worktree remove`가 수정되거나 추적 안 된 파일이 있다고 거부하면 `git -C <worktree 경로> status --short`로 남은 것을 보고하고, 사용자가 허락할 때만 `--force`를 붙인다.
   - `branch -d`가 머지되지 않은 브랜치라고 거부하면 squash나 rebase로 머지한 경우다. `gh pr view <N> --json state`로 MERGED를 확인하고 영향 범위를 한 줄 알린 뒤 `-D`로 지운다.
4. 세션이 처음부터 worktree 안에서 시작했으면 작업 디렉터리가 그 worktree라서 3단계를 할 수 없다. 지울 명령을 완료 보고에 적고, 사용자가 세션을 닫은 뒤 지우게 한다.
5. 남은 것을 확인한다.

   ```bash
   git -C <메인> worktree list
   git -C <메인> branch --list <브랜치>
   git ls-remote --heads origin <브랜치>
   ```

   로컬 브랜치가 남았으면 `git -C <메인> branch -d <브랜치>`로 지운다. 원격 브랜치가 남았으면 저장소가 머지된 브랜치를 자동으로 지우지 않는 설정이라 `git -C <메인> push origin --delete <브랜치>`로 지운다.

## 대기열

메인 체크아웃의 `LOCAL-SESSIONS.md`를 고친다.

- 행의 상태를 머지로 바꾼다. 배포 묶음 칸이 비어 있어 배포할 것이 없는 세션이면 행을 지운다.
- 진행 중인 세션과 다음 세션을 적는 절이 있으면 함께 고친다.
- 같은 배포 묶음의 행이 모두 머지 상태면 배포 차례라고 알린다.
- 세션 중에 뒤 세션의 할 일, 손댈 파일, 여는 날짜를 바꿀 사실이 나왔으면 그 행에 적고 보고한다.

## 배포 뒤 확인 묶음

행의 배포 뒤 확인 칸이 차 있거나 세션 중에 운영에서 볼 것이 생겼으면, 메인 체크아웃의 `LOCAL-TRACK.md`에 묶음을 하나 만든다. 파일에 있는 묶음 형식을 따르고, 묶음 밖 항목을 모으는 절이 있으면 그 앞에 넣는다. 파일이 비어 있으면 아래 형식을 쓴다.

```markdown
## <바꾼 내용을 담은 명사구>
<M/D> 머지 · 이슈 #N · PR #M

무엇을 바꿨는지 한 문단.

- [ ] <볼 것> · 확인: db · 닫는 기준: 배포 뒤 3일 안에 1건 이상 기록
- [ ] <안 나와야 하는 것> · 확인: 대화 · 닫는 기준: 배포 뒤 대화 5회 동안 0건이면 통과

확인 결과:
```

확인 방법은 db, 로그, 슬랙, 대화 가운데 하나를 적는다. 닫는 기준에는 기간이나 횟수와 통과 조건을 함께 적어서, 나중에 그 항목만 읽고 닫을지 정할 수 있게 한다.

## 로컬 보조 문서

- 어필 포인트를 모으는 gitignored 파일이 있고 이번 세션에 비자명한 기술 결정이나 작업 방식이 있었으면 후보로 제안하고, 사용자가 받으면 적는다.
- 묶음 이슈가 끝난 세션이면 그 묶음을 추적하던 메모리 파일을 유지, 갱신, 폐기로 나눠 제안하고 동의를 받은 뒤 고친다.
